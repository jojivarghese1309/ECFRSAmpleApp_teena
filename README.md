## ECFRTest_App

This repository contains the ECFRTest_App, a .NET Console application.

### Prerequisites

- .NET SDK 10.0 or later

### Building the Application

To build the ECFRTest_App, navigate to the project directory and run:

```bash
cd ECFRTest_App
dotnet build
```

### Running the Application

To run the ECFRTest_App:

```bash
cd ECFRTest_App
dotnet run
```

Or run the built executable:

```bash
cd ECFRTest_App/bin/Debug/net10.0
./ECFRTest_App
```

### Project Structure

- `ECFRTest_App/` - Main application directory
  - `Program.cs` - Application entry point
  - `ECFRTest_App.csproj` - Project configuration file
